# Git Commands Cheat Sheet

## What you have now practised

| Area | Commands |
|---|---|
| Saving work | `status`, `add`, `commit`, `diff`, `diff --staged` |
| Sharing | `push`, `push -u`, `fetch`, `pull` |
| Branches | `switch`, `switch -c`, `branch -a`, `branch -d`, `branch -D`, `merge` |
| Conflicts | `merge`, `merge --abort`, resolving in VS Code |
| Undo | `restore`, `restore --staged`, `commit --amend`, `reset --soft`, `revert` |
| Setting aside | `stash`, `stash list`, `stash pop` |
| History | `log`, `show`, `blame` |
| Advanced | `rebase`, `push --force-with-lease`, `push origin --delete` |
